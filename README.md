# Prompt Injection Escape Room

A short, fictional browser-based challenge for learning how to recognize prompt-injection attempts in untrusted text.

## Overview

Work through three scenarios, inspect the suspicious content, and choose the safest next action. The exercise demonstrates why instructions embedded in documents, READMEs, or emails should be treated as content to analyse rather than automatically followed.

## What you can explore

- Play through three fictional scenarios.
- Read the context and inspect the suspicious text in each room.
- Toggle Guardrail mode.
- Choose what you think is the safest next move and receive feedback.
- Use a hint, which costs one point.
- Track your points, safe streak, and rooms solved.
- Move to the next room or restart the challenge.
- Open the safety checklist.
- Switch between light and dark themes.

## How to run

1. Download `prompt-injection-escape-room.html`.
2. Open the file in a modern web browser.
3. Read each scenario and choose a response.

No installation or build step is required.

## Safety note

The scenarios are fictional and the exercise runs in the browser. It is intended for awareness and learning; it does not test or certify the security of an actual AI system.
